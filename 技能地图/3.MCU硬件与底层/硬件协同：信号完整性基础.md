
## 1. 学习目标

### 理解

- 理解**信号完整性（Signal Integrity，SI）不是“波形是否好看”，而是信号在发送、传输、接收全过程中是否满足电压、时序、噪声和可靠性约束**。
- 理解以下概念之间的关系：
    - 上升时间与带宽。
    - 传输线与反射。
    - 特性阻抗与端接。
    - 串扰与回流路径。
    - 过冲、下冲、振铃与接收器门限。
    - 抖动、时序裕量与误码率。
- 理解 PCB 走线、封装、过孔、连接器、电源和固件 GPIO 配置共同构成一个完整的信号通道。

### 掌握

- 掌握何时必须按照传输线处理数字信号。
- 掌握单端信号、差分信号、点到点、点到多点拓扑的基本审查方法。
- 掌握源端串联端接、并联端接、AC 端接和终端匹配的选型逻辑。
- 掌握 PCB 走线宽度、介质厚度、参考平面、换层和回流路径的基本约束。
- 掌握使用示波器、差分探头、TDR、VNA 和逻辑分析仪进行基础 SI 测试。

### 精通

- 能够从芯片 IBIS 模型、驱动能力、输出阻抗和接收门限分析信号裕量。
- 能够建立信号通道的等效模型，分析反射、串扰、损耗和时序偏差。
- 能够定位“低速协议但高速边沿”导致的 SI 问题。
- 能够区分 SI 问题、电源完整性问题、地弹问题和 EMI 问题的边界与耦合关系。

### 能够设计

- 能够为 SPI、QSPI、SDIO、RMII、MIPI、LVDS、CAN FD 等接口制定 SI 设计约束。
- 能够建立板级 SI Review Checklist 和实验验证流程。
- 能够设计可调试、可降速、可端接、可观测的硬件—固件协同方案。
- 能够根据接口速率、边沿、拓扑和距离选择合适的 PCB 层叠与端接方案。

## 3. 技术概述

### 3.1 什么是信号完整性

对于一个数字信号，接收端实际关心的不是发送端“逻辑上发送了 0 或 1”，而是：

1. 电压是否在规定时间内跨越输入门限。
2. 信号是否满足 Setup/Hold 时间。
3. 是否存在过冲、下冲和振铃导致误触发。
4. 是否有足够的噪声容限。
5. 多个信号之间是否存在串扰。
6. 在全温、全压、全速和全负载条件下是否稳定。
7. 是否满足误码率和长期可靠性目标。

因此，信号完整性本质上是：

> **发送器、封装、PCB 走线、过孔、连接器、接收器、电源和参考地共同形成的时域与频域信号传输质量。**

### 3.2 数字信号不是理想方波

理想方波包含无限高次谐波，真实数字信号的有效频谱主要由上升时间决定。

常用近似：

fknee≈0.35trfknee​≈tr​0.35​

其中：

- fkneefknee​：信号的主要频谱拐点。
- trtr​：10%～90% 上升时间。

例如：

- tr=1nstr​=1ns

则：

fknee≈350MHzfknee​≈350MHz

这意味着一个只有 10 MHz 的控制信号，如果边沿为 1 ns，其 PCB 设计仍可能需要按照数百 MHz 的传输特性处理。

### 3.3 主要技术分支

|分支|关注对象|典型问题|
|---|---|---|
|反射分析|单条信号通道|过冲、下冲、振铃、双边沿|
|串扰分析|相邻信号与参考平面|NEXT、FEXT、耦合噪声|
|时序分析|多信号相对关系|Setup/Hold 违例、偏斜|
|差分信号分析|差分对|共模转换、差分失衡|
|高速接口分析|受控阻抗通道|眼图闭合、抖动、损耗|
|电源与地耦合|PDN、地弹|电源噪声、门限漂移|
|封装与过孔分析|3D 互连结构|Stub、寄生电感、阻抗不连续|
|测量系统分析|探头和夹具|测量失真、探头负载|

## 5. 底层原理与功能特性深度解析

## 5.1 传输线与特性阻抗

### 5.1.1 传播延迟

信号在 PCB 走线上的传播速度通常约为：

- 外层微带线：约 150～180 mm/ns。
- 内层带状线：约 130～170 mm/ns。

估算传播延迟：

tpd=Lvptpd​=vp​L​

例如：

- 走线长度：150 mm。
- 传播速度：160 mm/ns。

tpd=150160≈0.94nstpd​=160150​≈0.94ns

如果信号上升时间为 1 ns，这条走线的单程延迟已经接近边沿时间，必须认真分析传输线效应。

### 5.1.2 什么时候必须使用传输线模型

常用经验判断：

tpd>tr6tpd​>6tr​​

或者使用临界长度：

Lcritical≈vp⋅tr6Lcritical​≈6vp​⋅tr​​

假设：

- vp=160mm/nsvp​=160mm/ns
- tr=1nstr​=1ns

则：

Lcritical≈26.7mmLcritical​≈26.7mm

**这不是绝对边界，而是进入重点审查的工程起点。**

### 5.1.3 特性阻抗

传输线特性阻抗可近似理解为：

Z0=L′C′Z0​=C′L′​​

其中：

- L′L′：单位长度电感。
- C′C′：单位长度电容。

对于 PCB，特性阻抗受以下因素影响：

- 走线宽度 WW。
- 铜厚 TT。
- 走线到参考平面的距离 HH。
- 介电常数 εrεr​。
- 阻焊层。
- 相邻走线和地铜形状。

工程上不建议仅用理论公式代替板厂阻抗计算。应使用：

- 板厂叠层阻抗计算工具。
- 2D Field Solver。
- 制造商实际叠层和材料参数。
- TDR 实测结果。

## 5.2 反射原理

### 5.2.1 反射系数

当信号从阻抗 Z1Z1​ 传输到 Z2Z2​ 时，电压反射系数为：

Γ=Z2−Z1Z2+Z1Γ=Z2​+Z1​Z2​−Z1​​

#### 开路

Z2→∞Z2​→∞Γ=+1Γ=+1

电压完全同相反射。

#### 短路

Z2=0Z2​=0Γ=−1Γ=−1

电压完全反相反射。

#### 50 Ω 传输线接 75 Ω 负载

Γ=75−5075+50=0.2Γ=75+5075−50​=0.2

即会产生 20% 的入射电压幅度反射。

### 5.2.2 反射形成振铃

一个典型信号路径为：

```
驱动器 ── 封装 ── PCB 走线 ── 过孔 ── 连接器 ── 接收器
```

每个阻抗不连续点都会产生部分反射：

- 驱动器输出阻抗不匹配。
- 走线宽度变化。
- 过孔焊盘过大。
- 参考平面切换。
- 连接器引脚和焊盘。
- 接收器输入电容。

多个反射叠加后会形成：

- 过冲。
- 下冲。
- 振铃。
- 双边沿。
- 门限重复穿越。
- 数据采样错误。

### 5.2.3 源端串联端接

源端串联电阻的目标是：

Rdriver+Rseries≈Z0Rdriver​+Rseries​≈Z0​

例如：

- MCU 实际输出阻抗约 18 Ω。
- PCB 传输线阻抗约 50 Ω。

则初始串联电阻可选择：

Rseries≈50−18=32ΩRseries​≈50−18=32Ω

工程中可从 **22 Ω、27 Ω、33 Ω、39 Ω** 等标准值进行实测优化。

#### 端接配置代码

```
typedef enum {
    GPIO_SLEW_LOW = 0,
    GPIO_SLEW_MEDIUM,
    GPIO_SLEW_HIGH
} gpio_slew_t;

typedef struct {
    uint32_t pin;
    gpio_slew_t slew;
    uint8_t drive_strength;
    bool open_drain;
} gpio_si_config_t;

static const gpio_si_config_t spi_si_config = {
    .pin = SPI_CLK_PIN,
    .slew = GPIO_SLEW_MEDIUM,
    .drive_strength = 2U,
    .open_drain = false
};

bool board_configure_spi_signal(const gpio_si_config_t *config)
{
    if (config == NULL) {
        return false;
    }

    if (!gpio_is_valid(config->pin)) {
        return false;
    }

    if (config->drive_strength > GPIO_DRIVE_MAX) {
        return false;
    }

    gpio_set_slew_rate(config->pin, config->slew);
    gpio_set_drive_strength(config->pin, config->drive_strength);
    gpio_set_open_drain(config->pin, config->open_drain);

    return true;
}
```

**注意：软件配置不能替代 PCB 端接设计。**  
GPIO Slew、驱动强度和外部串联电阻应该联合调节。

## 5.3 上升时间、带宽与振铃

### 5.3.1 上升时间与有效带宽

常用估算：

BW≈0.35trBW≈tr​0.35​

如果：

- tr=2nstr​=2ns

则：

BW≈175MHzBW≈175MHz

示波器带宽至少应高于被测信号有效带宽，通常建议：

BWscope≥3∼5×BWsignalBWscope​≥3∼5×BWsignal​

但具体测量还需考虑探头、连接器和校准误差。

### 5.3.2 振铃频率

一阶近似下，振铃频率可能由走线往返延迟或 LC 网络决定。

对于走线反射：

fring≈12tflightfring​≈2tflight​1​

例如单程传播时间为 1 ns：

fring≈12ns=500MHzfring​≈2ns1​=500MHz

如果示波器上出现约 500 MHz 振铃，可能与该走线的往返传播有关。

### 5.3.3 固件层降低边沿速度

```
typedef struct {
    uint32_t frequency_hz;
    uint32_t trace_length_mm;
    bool has_external_termination;
} signal_profile_t;

gpio_slew_t select_gpio_slew(const signal_profile_t *profile)
{
    if (profile == NULL) {
        return GPIO_SLEW_LOW;
    }

    /*
     * 这里的规则只是初始配置策略，
     * 最终值必须结合波形、时序和误码测试。
     */
    if ((profile->frequency_hz <= 1000000U) &&
        (profile->trace_length_mm <= 100U)) {
        return GPIO_SLEW_LOW;
    }

    if ((profile->frequency_hz <= 25000000U) ||
        profile->has_external_termination) {
        return GPIO_SLEW_MEDIUM;
    }

    return GPIO_SLEW_HIGH;
}
```

工程上要避免以下错误：

```
/* 错误：所有 IO 无差别配置为最快边沿。 */
gpio_set_slew_rate(SPI_CLK_PIN, GPIO_SLEW_HIGH);
gpio_set_slew_rate(LED_PIN, GPIO_SLEW_HIGH);
gpio_set_slew_rate(RELAY_PIN, GPIO_SLEW_HIGH);
```

## 5.4 接收器门限与噪声容限

接收器并不要求波形精确达到理想电压，而是关注是否满足门限。

典型参数：

- VIH(min)VIH(min)​：输入识别为高的最低电压。
- VIL(max)VIL(max)​：输入识别为低的最高电压。
- VOH(min)VOH(min)​：驱动器输出高电平最低值。
- VOL(max)VOL(max)​：驱动器输出低电平最高值。

高电平噪声容限：

NMH=VOH(min)−VIH(min)NMH​=VOH(min)​−VIH(min)​

低电平噪声容限：

NML=VIL(max)−VOL(max)NML​=VIL(max)​−VOL(max)​

例如：

- VOH(min)=2.9VVOH(min)​=2.9V
- VIH(min)=2.0VVIH(min)​=2.0V

则：

NMH=0.9VNMH​=0.9V

但实际系统中的有效噪声容限还必须扣除：

- 电源噪声。
- 地弹。
- 串扰。
- 接收器阈值漂移。
- 过冲和下冲。
- 温度和工艺偏差。

因此，不能只依据静态数据手册参数判断信号安全。

## 5.5 回流路径与参考平面

### 5.5.1 高频回流路径

在高频下，回流电流集中在信号线下方的参考平面区域，而不是平均流经整个地平面。

当信号参考面连续时：

```
顶层信号线
──────────────►

内层连续 GND
──────────────
回流电流集中在信号线正下方
```

当信号跨越平面分割时：

```
顶层信号线
──────►  ║  ──────►
          ║
参考平面   ║ 被迫绕行
```

结果是：

- 环路面积增大。
- 电感增加。
- 共模电流增大。
- 辐射和串扰增加。
- 阻抗不连续。
- 波形质量下降。

### 5.5.2 信号换层

信号换层时，应同时检查：

1. 新旧参考平面是否相同。
2. 参考平面是否连续。
3. 是否有足够近的回流过孔。
4. 是否存在平面切换。
5. 是否有过孔 Stub。
6. 是否有差分对不对称。
7. 是否增加额外串联电感。

#### 回流过孔布局示意

```
GND stitching via       GND stitching via
        ○                       ○

Signal via
    ●
```

回流过孔与信号过孔之间的距离应尽量小，但不能破坏制造间距和阻抗结构。

## 5.6 串扰原理

### 5.6.1 串扰来源

相邻信号之间存在：

- 互电容。
- 互电感。
- 共同参考平面阻抗。
- 共同电源阻抗。
- 连接器和封装内部耦合。

串扰通常分为：

- **NEXT：近端串扰**。
- **FEXT：远端串扰**。

### 5.6.2 影响串扰的主要因素

|因素|影响|
|---|---|
|平行长度增加|串扰增加|
|线间距减小|串扰增加|
|信号边沿变快|串扰增加|
|参考平面距离增加|串扰增加|
|走线靠近板边|辐射和耦合风险增加|
|回流路径中断|串扰和 EMI 增加|
|受害线处于高阻状态|更容易被干扰|

### 5.6.3 典型布线经验

- 优先增大线间距，而不是盲目压缩线宽。
- 关键高速线之间尽量避免长距离平行。
- 经验上可将线间距设置为 **3W 以上**作为初始规则，其中 WW 为线宽。
- 高速线与板边的距离应避免过近，常从 **3H 以上**开始评估，其中 HH 为到参考平面的距离。
- 时钟线、复位线、模拟输入线应远离高速数据线。
- 不要让高速线从高阻抗模拟节点旁边经过。

### 5.6.4 受害线下拉和状态控制

```
typedef enum {
    INPUT_FLOATING = 0,
    INPUT_PULL_UP,
    INPUT_PULL_DOWN
} input_bias_t;

bool configure_sensitive_input(uint32_t pin, input_bias_t bias)
{
    if (!gpio_is_valid(pin)) {
        return false;
    }

    /*
     * 高阻悬空输入对串扰极其敏感。
     * 通过确定性偏置降低误触发概率。
     */
    gpio_set_mode(pin, GPIO_MODE_INPUT);
    gpio_set_bias(pin, bias);

    return true;
}
```

这不能替代 PCB 隔离，但能够降低受害节点阻抗和随机翻转概率。

## 5.7 差分信号基础

### 5.7.1 差分电压和共模电压

差分电压：

Vdiff=VP−VNVdiff​=VP​−VN​

共模电压：

Vcm=VP+VN2Vcm​=2VP​+VN​​

理想差分接收器主要检测 VdiffVdiff​，抑制共模变化。

### 5.7.2 差分对设计要点

- 差分阻抗满足接口要求。
- 差分对内两根线长度和环境尽量对称。
- 两根线尽量同时换层。
- 使用相同数量和类型的过孔。
- 避免一根线靠近过孔阵列，另一根线远离。
- 保证参考平面连续。
- 不要将差分对拆到两个不相关的走线层。
- 避免过度蛇形等长。

### 5.7.3 差分不平衡导致共模转换

差分对的不对称会把差模能量转换为共模能量，从而：

- 增大 EMI。
- 降低接收器抗干扰能力。
- 造成眼图不对称。
- 使线缆辐射增大。

差分对长度偏差引入时延差：

Δt=ΔLvpΔt=vp​ΔL​

若：

- ΔL=5mmΔL=5mm
- vp=160mm/nsvp​=160mm/ns

则：

Δt≈31.25psΔt≈31.25ps

是否满足要求，必须结合接口时序预算，而不是机械使用统一长度差规则。

## 5.8 过孔、Stub 和阻抗不连续

### 5.8.1 过孔寄生

过孔可以等效为：

- 串联电感。
- 对地电容。
- 未使用部分形成 Stub。
- 焊盘和防焊开窗形成额外电容。

高频电感阻抗：

XL=2πfLXL​=2πfL

假设：

- L=1nHL=1nH
- f=1GHzf=1GHz

则：

XL≈6.28ΩXL​≈6.28Ω

对于低电压高速信号，这已经可能明显影响波形。

### 5.8.2 Stub

Stub 是信号路径中不参与主要传输、但仍然连接到主线的支路。

```
主线 ───────────────
              │
              │ Stub
              │
```

Stub 的往返反射会在主信号上形成额外振铃。高速设计中常见措施：

- 盲埋孔。
- 背钻。
- 减少过孔层间长度。
- 优化换层位置。
- 避免测试点形成长 Stub。
- 对不关键网络使用较低边沿速度。

## 5.9 测量系统本身对 SI 的影响

### 5.9.1 被动探头问题

典型 10× 被动探头可能具有：

- 约 10 MΩ 输入电阻。
- 约 8～15 pF 输入电容。
- 较长地线引入明显寄生电感。

探头输入电容会与信号源阻抗形成低通网络：

f−3dB=12πRsCpf−3dB​=2πRs​Cp​1​

例如：

- Rs=50ΩRs​=50Ω
- Cp=10pFCp​=10pF

f−3dB≈318MHzf−3dB​≈318MHz

而长鳄鱼地线可能引入数十 nH 电感，使测量波形出现“假振铃”。

### 5.9.2 正确测量原则

- 高速边沿优先使用有源探头。
- 使用短弹簧地或同轴探测方式。
- 探头带宽至少覆盖信号主要频谱。
- 测量前进行探头校准。
- 在接收端和发送端分别测量。
- 不要只在测试点测量而忽略测试点本身的 Stub。

系统可用时序裕量可写为：

Tmargin=Tavailable−Tdata_delay−Tclock_skew−Tjitter−Tsetup−TuncertaintyTmargin​=Tavailable​−Tdata_delay​−Tclock_skew​−Tjitter​−Tsetup​−Tuncertainty​

### 6.6 功耗与边沿速度

CMOS 动态功耗近似：

Pdynamic=αCV2fPdynamic​=αCV2f

其中：

- αα：翻转活动因子。
- CC：等效负载电容。
- VV：电源电压。
- ff：翻转频率。

虽然公式没有直接包含边沿时间，但高速边沿通常意味着：

- 更大的瞬态驱动电流。
- 更高的短路电流。
- 更强的高频谐波。
- 更严重的电源和地弹噪声。

### 6.7 主要性能瓶颈

|瓶颈|根因|优化方法|典型收益|
|---|---|---|---|
|反射|阻抗失配|源端串联、控制拓扑|过冲降低 50%～80%|
|串扰|平行过长、间距过小|增大间距、缩短平行|串扰降低 30%～70%|
|时序不足|路径偏斜、抖动|等长、优化参考面|时序裕量增加数百 ps～数 ns|
|眼图闭合|损耗、反射、抖动|优化阻抗、减少过孔|眼高和眼宽增加|
|假振铃|测量方法错误|有源探头、短地|消除测量伪影|
|EMI 超标|共模回路过大|连续参考面、接口处理|辐射显著下降|

### 6.8 优化收益估算方法

建议每次只修改一个主因素：

```
版本 A：原始无端接
版本 B：增加源端串联电阻
版本 C：增加线间距
版本 D：修复回流路径
版本 E：降低 GPIO Slew
```

分别记录：

- 峰值过冲。
- 下冲幅度。
- 振铃衰减时间。
- 10%～90% 上升时间。
- 接收端门限穿越次数。
- 长时间误码数。
- 近场辐射峰值。

这样可以区分真正有效的整改措施，而不是依赖主观波形判断。

## 8. 工程最佳实践

### 8.1 SI 设计原则

1. **先控制边沿，再讨论时钟频率。**
2. **先定义叠层和参考平面，再开始高速布线。**
3. **优先使用点到点拓扑。**
4. **所有高速线必须有连续参考路径。**
5. **源端串联电阻应预留封装位置，便于样机调试。**
6. **避免在接收端附近形成测试点长 Stub。**
7. **差分对的对称性包括走线、过孔、焊盘和环境。**
8. **不使用无依据的过度蛇形等长。**
9. **高速信号应远离复位、晶振、模拟输入和高阻节点。**
10. **测试点、连接器、过孔和封装都属于信号通道的一部分。**
11. **板级 SI 必须结合电源完整性和回流路径审查。**
12. **设计应允许通过固件降低速率、降低边沿或切换驱动强度。**

### 8.2 选型决策矩阵

评分：

- 1：不推荐。
- 3：可接受。
- 5：推荐。

|方案|SI 性能|成本|功耗|调试灵活性|适用性|
|---|---|---|---|---|---|
|无端接|1～3|5|5|1|短距离、低边沿速率|
|源端串联端接|4|4|5|5|点到点单端信号|
|接收端并联端接|5|3|1～2|3|高速点到点|
|差分终端|5|4|3～5|3|LVDS、CAN、RS-485|
|ODT|4～5|4|4|2～3|FPGA、DDR、高速器件|
|降低 GPIO Slew|3～5|5|4|4|MCU 通用 IO|
|降低接口频率|5|5|3|5|非实时或可降级系统|

### 8.3 工业级编码规范

#### GPIO 配置必须显式声明 SI 属性

```
typedef struct {
    uint32_t pin;
    uint32_t function;
    uint32_t frequency_hz;
    uint32_t estimated_trace_mm;
    uint32_t slew_rate;
    uint32_t drive_strength;
    bool has_series_resistor;
} board_signal_constraint_t;
```

#### 高速接口必须具备运行时降级策略

```
typedef enum {
    LINK_RATE_SAFE = 0,
    LINK_RATE_NORMAL,
    LINK_RATE_HIGH
} link_rate_t;

bool link_set_rate(link_rate_t rate)
{
    switch (rate) {
    case LINK_RATE_SAFE:

               gpio_set_slew_rate(SPI_CLK_PIN, GPIO_SLEW_LOW);

    case LINK_RATE_NORMAL:
        return spi_set_frequency(25000000U) &&
               gpio_set_slew_rate(SPI_CLK_PIN, GPIO_SLEW_MEDIUM);
```

## 9. 常见错误与避坑指南

## 9.1 错误一：只看协议频率，不看边沿时间

### 错误代码

```
/* 错误认知：SPI 只有 1 MHz，因此不需要 SI 设计。 */
spi_set_frequency(1000000U);
gpio_set_slew_rate(SPI_CLK_PIN, GPIO_SLEW_HIGH);
```

### 根因分析

- SPI 频率为 1 MHz，但 GPIO 可能仍以 1 ns 边沿翻转。
- 1 ns 边沿对应约 350 MHz 的主要频谱。
- 较长走线、过孔和连接器仍会产生反射。

### 正确实现

```
void spi_low_rate_init(void)
{
    spi_set_frequency(1000000U);

    /*
     * 低频协议不等于应使用最快边沿。
     */
    gpio_set_slew_rate(SPI_CLK_PIN, GPIO_SLEW_LOW);
    gpio_set_slew_rate(SPI_MOSI_PIN, GPIO_SLEW_LOW);
    gpio_set_slew_rate(SPI_CS_PIN, GPIO_SLEW_LOW);
}
```

### 风险影响

- 过冲和振铃。
- 邻近模拟信号被串扰。
- EMC 辐射增加。
- 不同批次或不同线缆条件下偶发错误。

---

## 9.2 错误二：使用长鳄鱼夹地线测量高速波形

### 错误代码或操作

```
示波器探头尖端接 CLK
探头鳄鱼夹通过 10 cm 地线接板上 GND
```

### 根因分析

长地线引入寄生电感：

V=LdidtV=Ldtdi​

边沿越快，地线寄生电感产生的测量误差越大。示波器看到的振铃可能主要来自测量回路，而不是实际信号。

### 正确实现

```
优先级：
1. 有源探头 + 近端地
2. 同轴连接 + 50 Ω 端接
3. 探头短弹簧地
4. 避免长鳄鱼夹地线
```

### 风险影响

- 错误判断 PCB 质量。
- 误加串联电阻。
- 误删滤波器。
- 真实问题被测量伪影掩盖。

---

## 9.3 错误三：差分线只关注等长，不关注参考平面

### 错误布局

```
差分对：
P ────────────────
N ────────┐
          └── 换层
参考平面在换层区域被切断
```

### 根因分析

- 差分电流仍需要闭合回路。
- 参考平面切断会造成共模转换。
- 仅通过“P、N 等长”不能保证差分完整性。

### 正确实现

- 保持 P/N 同时换层。
- 检查换层区域参考平面连续。
- 为回流提供近端过孔或合理参考转换。
- 保证两根线使用相同过孔结构。
- 检查差分阻抗，而不仅是几何等长。

### 风险影响

- 眼图不对称。
- 共模辐射增加。
- EMI 测试失败。
- 长线缆下通信距离缩短。

---

## 9.4 错误四：所有高速信号都采用星型拓扑

### 错误布局

```
┌── 接收器 A
发送器 ───────┼── 接收器 B
              └── 接收器 C
```

### 根因分析

- 星型分支产生多个阻抗突变点。
- 每个支路都会产生反射。
- 多重反射叠加，接收端波形复杂。
- 分支长度接近边沿传播距离时，问题尤其严重。

### 正确实现

优先选择：

```
发送器 ───────── 接收器 A ───────── 接收器 B
```

或者：

- 使用总线专用收发器。
- 使用协议规定的端接方式。
- 控制每个支线长度。
- 采用缓冲器或重定时器。

### 风险影响

- 多节点条件下误码。
- 不同负载数量导致波形变化。
- 样机少节点正常，量产全节点失败。

---

## 9.5 错误五：高速线跨越地平面分割

### 错误布局

```
高速 CLK ───────────────►
参考 GND ─────── 断缝 ───────
```

### 根因分析

- 高频回流无法在信号正下方闭合。
- 回流绕行导致环路面积增大。
- 传输线阻抗发生突变。
- 共模电流和辐射增加。

### 正确实现

- 保持高速信号下方参考平面连续。
- 如果必须换参考平面，提供合理的参考跨接路径。
- 将地分割限制在经过电流分析且确有必要的区域。
- 对差分信号尤其检查共模回流路径。

### 风险影响

- 波形恶化。
- 时序偏差。
- 辐射增强。
- 对连接器和外部线缆更敏感。

## 9.6 错误六：盲目增加不同容值的去耦电容

### 错误实现

```
VDD 上并联：
100 pF + 1 nF + 10 nF + 100 nF + 1 uF + 10 uF
```

### 根因分析

- 不同电容的 ESR、ESL 和安装电感不同。
- 可能形成反谐振峰。
- 电源完整性问题会表现为信号完整性问题。
- 盲目增加电容可能在某个频段放大阻抗。

### 正确实现

- 根据 PDN 目标阻抗选择电容。
- 使用有效偏压下的容量参数。
- 通过仿真和实测检查反谐振。
- 将信号问题和电源噪声同步测量。

### 风险影响

- 时钟抖动。
- 接收器门限漂移。
- 多路 IO 同时翻转时出现错误。
- 低温、高温或不同负载下行为变化。

## 10.2 高速 SPI/QSPI 组合框架

### 硬件侧

- 源端串联电阻预留 0 Ω、22 Ω、33 Ω、47 Ω。
- CLK、数据、片选使用连续参考平面。
- 关键换层位置配置回流过孔。
- Flash 电源去耦靠近器件。
- 避免 CLK 与模拟、复位、晶振平行。

### 固件侧

- 上电使用低速读取 ID。
- 完成延迟校准后切换高速。
- 校验关键启动区 CRC。
- 发生错误时自动降速。
- 记录错误次数和当前速率。

### 代码框架

```
typedef struct {
    uint32_t frequency_hz;
    uint32_t crc_error_count;
    uint32_t timeout_count;
    bool calibrated;
} qspi_link_diag_t;

static qspi_link_diag_t qspi_diag;

static bool qspi_try_rate(uint32_t frequency_hz)
{
    platform_qspi_set_frequency(frequency_hz);
    platform_qspi_set_slew_rate(GPIO_SLEW_MEDIUM);

    if (!platform_qspi_read_id_valid()) {
        qspi_diag.timeout_count++;
        return false;
    }

    if (!platform_qspi_delay_calibrate()) {
        qspi_diag.crc_error_count++;
        return false;
    }

    if (!platform_qspi_crc_check_region(BOOT_REGION,
                                        4096U)) {
        qspi_diag.crc_error_count++;
        return false;
    }

    qspi_diag.frequency_hz = frequency_hz;
    qspi_diag.calibrated = true;
    return true;
}

bool qspi_initialize_with_fallback(void)
{
    static const uint32_t rates[] = {
        12000000U,
        25000000U,
        50000000U,
        80000000U
    };

    for (uint32_t i = 0U;
         i < (sizeof(rates) / sizeof(rates[0]));
         ++i) {
        if (qspi_try_rate(rates[i])) {
            return true;
        }
    }

    fault_log_write(FAULT_QSPI_SIGNAL_INTEGRITY,
                    qspi_diag.crc_error_count);

    return false;
}
```

### 设计要点

- 固件降级必须记录证据，否则无法区分板级问题和软件问题。
- 生产测试应覆盖不同串联电阻配置或固定最终 BOM。
- 高速模式切换前应完成延迟校准和数据完整性验证。

## 11. 工业级实际案例分析

## 11.1 案例一：SPI 传感器在量产板上偶发读错

### 需求

- MCU 主频 200 MHz。
- SPI 时钟 20 MHz。
- 传感器距离 MCU 120 mm。
- 连接器和柔性线缆引出。
- 工作温度 -20°C～70°C。

### 故障现象

- 实验室短线连接正常。
- 量产板部分设备偶发寄存器读错。
- 逻辑分析仪显示时序正常。
- 降低 SPI 到 5 MHz 后错误消失。

### 分析

逻辑分析仪只关注逻辑阈值和协议，不足以看清：

- 接收端振铃。
- 过冲和下冲。
- 门限多次穿越。
- 线缆连接器反射。
- 温度变化下的驱动能力变化。

### 原因

1. MCU GPIO 使用最高 Slew。
2. CLK 无源端串联电阻。
3. 走线跨越局部地分割。
4. 连接器附近存在长支路。
5. 传感器电源噪声与 SPI 同时发生。

### 整改

- CLK、MOSI、CS 源端增加 33 Ω。
- 修复连续参考平面。
- 缩短连接器支线。
- GPIO 改为中速边沿。
- 传感器端增加局部去耦。
- 增加 SPI CRC 和错误重试。

### 结果参考

|指标|整改前|整改后|
|---|---|---|
|接收端 CLK 过冲|0.95 V|0.28 V|
|24 小时错误次数|17 次|0 次|
|最高稳定速率|5 MHz|20 MHz|
|低温错误|偶发|未复现|

### 设计要点

- 逻辑分析仪正常不代表模拟波形合格。
- 低速协议如果边沿很快，仍可能出现严重反射。
- 线缆、连接器和测试点必须纳入信号通道。

## 11.2 案例二：CAN FD 总线在长线缆下通信不稳定

### 需求

- CAN FD，仲裁段 500 kbit/s。
- 数据段 2 Mbit/s。
- 总线长度 20 m。
- 8 个节点。
- 工业现场有变频器和电机。

### 故障现象

- 短线测试稳定。
- 接入 20 m 线缆后出现错误帧。
- 仅在电机启动时明显。
- 某些节点重启后暂时恢复。

### 原因分析

1. 总线两端端接不正确。
2. 中间节点错误增加 120 Ω 终端。
3. 节点支线过长。
4. TVS 器件寄生电容过大。
5. 连接器屏蔽和地参考处理不一致。
6. 电机启动时共模瞬态超出收发器能力。

### 整改措施

- 仅在总线两端配置 120 Ω 终端。
- 中间节点移除终端电阻。
- 缩短各节点支线。
- 选用低电容 CAN 专用 TVS。
- 优化连接器屏蔽和机壳泄放路径。
- 软件统计错误帧、Bus-Off 和恢复次数。

### 设计要点

- 差分协议不是“天然不怕干扰”。
- 差分信号依赖阻抗、共模范围、回流和拓扑共同成立。
- 终端电阻位置错误会直接改变整个总线的阻抗。

## 11.3 案例三：RMII Ethernet 启动偶发失败

### 需求

- MCU 集成 Ethernet MAC。
- 外接 PHY。
- RMII 50 MHz 参考时钟。
- 100BASE-TX。
- 需要满足工业温度等级。

### 故障现象

- 室温 100% 启动。
- 高温和低电压时部分板卡无法建立链路。
- 降低系统主频不能解决。
- 更换 PHY 批次后问题概率变化。

### 分析路径

1. 检查 REF_CLK 时序。
2. 观察 MAC 端和 PHY 端时钟波形。
3. 检查时钟源配置。
4. 测量数据线到达时间差。
5. 检查参考平面和差分/单端阻抗。
6. 检查 PHY 电源纹波和复位时序。

### 发现的问题

- 50 MHz 时钟走线经过换层，回流过孔距离较远。
- 时钟线没有源端阻尼。
- PHY 复位释放时间过短。
- 3.3 V 电源在 PHY 发射瞬间存在明显跌落。
- MAC 与 PHY 的时序窗口在高温下缩小。

### 整改

- 时钟源端增加串联阻尼。
- 修复换层回流。
- 延长 PHY 复位释放后的稳定等待时间。
- 优化 PHY 去耦和电源回路。
- 增加上电时钟有效性检测。

### 固件时序框架

```
bool ethernet_phy_startup(void)
{
    platform_phy_reset_assert();

    platform_delay_ms(10U);

    if (!platform_phy_power_good()) {
        return false;
    }

    platform_phy_reset_release();

    /*
     * 等待 PHY 内部 PLL、参考时钟和模拟电路稳定。
     */
    platform_delay_ms(50U);

    for (uint32_t retry = 0U; retry < 10U; ++retry) {
        if (phy_is_clock_valid() &&
            phy_read_id_valid() &&
            phy_link_status_valid()) {
            return true;
        }

        platform_delay_ms(10U);
    }

    fault_log_write(FAULT_PHY_STARTUP, 0U);
    return false;
}
```

## 12. 高频问题深度答疑

### 12.1 低频 GPIO 是否可以忽略信号完整性？

不能仅按频率判断。应重点看：

- 上升/下降时间。
- 走线长度。
- 负载电容。
- 是否连接外部线缆。
- 是否靠近模拟和高阻节点。
- 是否驱动继电器、电机或其他强干扰负载。

一个 1 MHz 信号，如果边沿为 1 ns，仍可能表现出数百 MHz 的高频特征。

### 12.2 50 Ω 阻抗是否所有信号都必须满足？

不是。50 Ω 是常见单端目标值，但具体应由以下因素决定：

- 接口协议要求。
- 驱动器输出阻抗。
- 接收器输入结构。
- 线缆阻抗。
- 差分还是单端。
- 板厂叠层和成本约束。

低速、短距离、低边沿信号未必需要严格 50 Ω，但必须保证没有明显反射和时序风险。

### 12.3 源端串联电阻为什么能减少反射？

因为它增加了驱动器端的等效输出阻抗，使：

Rdriver+Rseries≈Z0Rdriver​+Rseries​≈Z0​

当源端匹配时，信号到达负载后产生的反射返回源端时，会被源端吸收，而不是继续反射回传输线。

但源端串联电阻会：

- 降低边沿速度。
- 增加传播延迟。
- 影响多接收器拓扑。
- 可能不适合双向信号。

### 12.4 为什么加了串联电阻后反而通信失败？

可能原因：

1. 电阻过大，接收端上升时间过慢。
2. 采样窗口过窄。
3. 双向总线方向切换时未正确匹配。
4. 端接位置错误。
5. 原始问题不是反射，而是电源或时钟问题。
6. 串联电阻与输入电容形成过强 RC 滤波。

估算上升时间：

tr≈2.2RsourceCloadtr​≈2.2Rsource​Cload​

例如：

- R=100ΩR=100Ω
- C=20pFC=20pF

tr≈2.2×100×20pF=4.4nstr​≈2.2×100×20pF=4.4ns

对于高速时序，4.4 ns 可能已经过慢。

### 12.5 差分信号是否不需要地线？

需要。差分信号虽然主要通过两根信号线闭合差分电流，但仍然需要：

- 合理的共模回流路径。
- 参考地。
- 共模电压边界。
- ESD 和瞬态泄放路径。
- 连接器和线缆的屏蔽/机壳参考。

完全忽略地参考可能导致共模范围超限和 EMI 恶化。

### 12.6 眼图好看是否代表系统一定可靠？

不一定。眼图通常是在特定条件下统计得到的。还需要验证：

- 全温、全压、全速。
- 不同器件批次。
- 不同线缆和连接器。
- 电源扰动。
- EMC 注入。
- 长时间误码率。
- 接收器实际采样点和协议时序。

眼图是重要证据，但不是唯一证据。

### 12.7 为什么示波器上看不到问题，但系统仍然报错？

可能原因：

- 测量位置不在接收端。
- 探头带宽不足。
- 采样率或存储深度不足。
- 触发条件不对。
- 错误只在特定电源、温度或负载出现。
- 问题来自 Setup/Hold，而不是明显过冲。
- 电源噪声或地弹导致接收器门限移动。
- 测量过程中探头改变了电路负载。

应同时进行：

- 接收端模拟波形测量。
- 时序测量。
- 电源和地噪声测量。
- 错误计数。
- 边界条件压力测试。

## 13. 课程核心总结

### 核心要点

- **信号完整性由边沿速度、传输线、阻抗、回流、端接、拓扑和接收器时序共同决定。**
- **协议频率不是判断 SI 风险的唯一甚至不是首要指标，边沿时间通常更关键。**
- **传播延迟达到边沿时间的约六分之一时，就应认真考虑传输线效应。**
- **特性阻抗不连续会产生反射；端接的目标是控制反射，而不是让波形看起来完美。**
- **连续参考平面和低阻抗回流路径是 SI 设计的基础。**
- **差分对不仅需要等长，还需要阻抗、参考平面、过孔和环境对称。**
- **过孔、测试点、连接器和封装都属于信号通道，不能只审查 PCB 平面走线。**
- **固件可以通过 Slew、驱动强度、速率、延迟校准和降级机制增强系统韧性。**
- **示波器测量本身可能改变被测信号，必须控制探头和接地方式。**

### 性能排序

一般情况下，影响 SI 的优先级可按以下顺序考虑：

```
边沿速度与驱动器输出阻抗
> 回流路径与参考平面连续性
> 拓扑和端接
> 阻抗控制
> 过孔、Stub 和连接器
> 串扰与平行长度
> 时序偏斜与抖动
> 测量与验证方法
```

### 通用选型结论

- 点到点单端高速信号：优先考虑**源端串联端接**。
- 多节点总线：优先采用**协议规定拓扑和终端方式**。
- 外部差分接口：必须同时审查**阻抗、共模范围、终端、回流和防护**。
- MCU 通用 GPIO：优先使用**满足时序的最低边沿速度**。
- 复杂高速接口：必须结合**叠层、IBIS、仿真、示波器和误码测试**。
- 设计中应保留**端接调试位、速率降级和错误统计能力**。

## 16. 实践与进阶路径

### 16.1 梯度实战任务

#### 任务一：测量 GPIO 边沿与有效带宽

1. 选择一个 MCU GPIO。
2. 分别配置低、中、高 Slew。
3. 测量 10%～90% 上升时间。
4. 根据 0.35/tr0.35/tr​ 估算有效带宽。
5. 对比不同驱动强度下的过冲和振铃。
6. 记录波形和电源纹波变化。

#### 任务二：SPI 源端端接实验

准备以下串联电阻：

```
0 Ω
22 Ω
33 Ω
47 Ω
68 Ω
```

分别测量：

- 发送端波形。
- 接收端波形。
- 过冲和下冲。
- 上升时间。
- 采样裕量。
- 长时间 CRC 错误率。

最终建立：

```
阻值 → 波形质量 → 时序 → 误码率 → 推荐配置
```

#### 任务三：回流路径对比

设计两种 PCB 走线：

```
版本 A：连续参考平面
版本 B：跨越参考平面分割
```

对比：

- 接收端振铃。
- 近场辐射。
- 串扰。
- 电源噪声。
- 接口误码。

该实验可以直观看到**参考平面对 SI 和 EMC 的决定性影响**。

#### 任务四：串扰实验

建立三根线：

```
Aggressor ── 高速时钟
Victim A  ── 高阻输入
Victim B  ── 有下拉输入
```

改变：

- 线间距。
- 平行长度。
- Slew。
- 受害线阻抗。
- 参考平面距离。

记录受害线峰值干扰和门限穿越次数。

#### 任务五：差分对不对称实验

分别改变：

- P/N 长度差。
- 过孔数量。
- 走线间距。
- 参考平面连续性。
- 连接器引脚环境。

观察：

- 差分眼图。
- 共模电压。
- EMI 近场辐射。
- 长线缆误码率。

#### 任务六：建立高速接口自动化测试

固件至少记录：

```
typedef struct {
    uint32_t total_frames;
    uint32_t crc_errors;

    uint32_t retry_count;
    uint32_t current_rate;
    int32_t  temperature_mc;
    uint16_t supply_mv;

```

测试维度：

- 速率。
- 温度。
- 电源电压。
- 端接阻值。
- 线缆长度。
- 负载数量。
- GPIO Slew。
- 驱动强度。
